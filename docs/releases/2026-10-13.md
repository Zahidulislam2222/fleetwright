### Included behavior

- Durable tenant-scoped catalogue crawling with pinned HTTP/TLS egress, bounded physical fetches,
  JSON/CSS contracts, quality guards, cancellation, retention and private console JSONL export.
- Standalone SQLite/Ollama browser application with three maintained form workflows, exact human
  approval, receipts, private state and optional isolated CDP that preserves existing tabs.
- Database-clock account/group pacing, bounded cell fairness and durable raw-detection handover.
- Renewable observe-only monitoring, independent public probes, encrypted off-host recovery,
  script-hash CSP, offline AWS reference and independently verifiable signed release inventory.
- Signal-aware crawler cancellation and resilient retired-slot cleanup, with explicit configured
  shutdown grace for all browser/execution workers.

### Shipped behavior

Two versioned owned workflows support freight booking and maintenance-request creation.
Six MCP tools expose contracts, durable submissions, progress, cancellation and bounded evidence.
Human approval binds the exact account, inputs and contract revision. PostgreSQL fencing,
database-clock leases and current scoped grants authorize execution and lookup. An interrupted
external action becomes `UNKNOWN`; reconciliation reads receipts before any decision about retry.
An inconclusive destination remains unknown for operator review.

The console supports owner review and evidence download. Existing freight workers retain a
separate account pool. Workflow authentication recovers expired/revoked cached sessions within
account ownership and lease bounds. Workflow audit events remain readable through the shared
API without adding a user authorization role.

### Boundaries recorded at rc5 publication

Python runtime and npm production dependency audits were clean. Full npm audit retains one
unpatched development-only `braces` advisory, propagated through five high-severity entries;
this finding is recorded without suppression. Source scanning found no real secret in the public
source snapshot. Changeable provider/endpoints, operational limits and maintained product copy
use typed configuration or validated data; workflow states, wire roles and MCP syntax remain
fixed protocol definitions. Private credentials and operational artifacts are excluded from Git.

The deployment is one server. Local archives do not establish independent disaster recovery.
External uptime probes, installed metrics collection/notification, encrypted off-host backups,
multi-zone operation, stronger CSP and larger browser-density runs remain acceptance-gated work.
One million concurrent users and 99% / 99.9% availability are future design objectives with a
capacity model and validation ladder, rather than measured service commitments.
